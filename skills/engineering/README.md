# 工程方法

本桶保留五项，集合分发和协作规则见根 [README.md](../../README.md)。

## 默认发现策略

- [diagnosing-bugs](diagnosing-bugs/SKILL.md)：按资源和授权边界诊断、修复并验证。
- [codebase-design](codebase-design/SKILL.md)：比较深模块、接口、seam 和测试设计。
- [prototype](prototype/SKILL.md)：用逻辑或界面原型回答具体不确定性。

## 仅显式调用

- [improve-codebase-architecture](improve-codebase-architecture/SKILL.md)：在已选范围形成有证据的改进候选。
- [retro](retro/SKILL.md)：结合实际会话与当前设施提出复盘候选。
