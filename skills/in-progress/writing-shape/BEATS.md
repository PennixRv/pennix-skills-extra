# 可选分支成文模式

分支成文沿用 [SKILL.md](SKILL.md) 的素材只读、目标文件、来源保真、概念铺垫、交互和编辑要求，按以下步骤选择后续叙述方向。

1. 在当前读者已具备的概念与已有正文基础上，给少量可达的起始或后续方向；每个方向说明它接续什么、将引入什么概念，以及会打开哪些后续路线。
2. 用户选择或给出自己的方向后，只写入已选择的块。一个块完成一个叙述动作，长度由实际论证需要决定；不提前写未选分支。
3. 复读成文目标，更新已铺垫概念，再提供下一组有意义的方向。若前文被用户实质改写，重新判断后续路线；已明确的方向和局部格式不重复询问。
4. 无可达方向时，区分缺素材、缺概念铺垫与文章已达目标；必要缺口按主体合同处理，不能用虚构事实接续。达到约定的成文目标即可结束，不要求用尽所有素材。

分支及答案保留在当前文章或现有写作记录，不新建分支状态库、任务或知识写入流程。
